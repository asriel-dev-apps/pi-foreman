# pi-foreman

コーディングエージェント [pi](https://github.com/earendil-works/pi) に、2 つの層を足す拡張です。
どちらも [TypeSafe の jev](https://docs.typesafe.ai) に判定を頼みます。jev は文章ではなく
確率を返すので、返ってきた値でそのまま分岐できます。

- **foreman** — 仕事に取りかかる前に一度だけ、依頼の規模と危なさを見て、進め方の助言を添えます
- **gate** — ツールを実行する直前に、取り返しのつかない操作を見つけて知らせます

助言と通知だけで、既定では何も止めません。

## 動かす

Node 23.6 以降と、[TypeSafe の API キー](https://console.typesafe.ai/keys)が要ります。

```bash
export TYPESAFE_API_KEY='...'
pi -e /path/to/pi-foreman
```

常時使うなら、`~/.pi/agent/extensions/` に再輸出するファイルを置きます。

```ts
// ~/.pi/agent/extensions/foreman.ts
export { default } from "/path/to/pi-foreman/extensions/foreman.ts";
```

シンボリックリンクでは動きません。リンクの位置を基準に相対 import が解決されるため、
拡張が参照している `../src/` を見失います。

片方だけ使いたいときは、ディレクトリではなくファイルを指してください。
`pi -e <ディレクトリ>` は `extensions/` の中身をすべて読み込みます。

キーがないと、拡張は何もせずに黙ります。pi はそのまま動きます。

## foreman

依頼文とリポジトリの状態をもとに、こういう段落を差し込みます。

```
着手前の見立て (助言であって指示ではない。合わないと思ったら従わなくてよい):
- 見立て: 規模 1.7/3、取り返しのつかなさ 69%。
- 受け入れる前に独立したレビュー (rv) を回すこと。
- 実装モデルの推奨: opus
```

jev に聞くのは、規模・取り返しのつかなさ・画面を変えるか・委譲できるか・仕事の種類の
5 つだけです。そこから先の文面は `src/foreman.ts` のルール表が決めるので、
自分の進め方に合わせて書き換えてください。仕事の種類ごとの一言 (`ADVICE_BY_KIND`) は、
手元の道具の名前を入れると具体的になります。

## gate

`bash` / `write` / `edit` の実行直前に、4 つのことを尋ねます。破壊的か、ローカルのデータを
外へ送るか、依頼の範囲を超えるか、意図しなかったときの被害はどれくらいか。

ただし、jev の答えだけでは決めません。**git に尋ねれば確定することは、手元で調べます。**

| 手元で調べること | 使うもの |
|---|---|
| 対象が git の無視対象か | `git check-ignore` |
| 対象に未コミットの変更があるか | `git status --porcelain` |
| git が追跡していない既存ファイルを上書きするか | `git ls-files` |
| git の履歴を書き換えるか | コマンドの形 |
| 作業ディレクトリの外を触るか | パスの解決結果 |

たとえば「ビルド成果物を消して」という依頼つきの `rm -rf build` は、jev の答えでは
破壊的 0.97 になります。しかし `build/` が `.gitignore` に載っていれば、消えても困りません。
逆に、未コミットの変更を含むファイルの削除は git から戻せないので、jev の答えが低くても
知らせます。

読むだけのコマンドは判定しません。送らなければ漏れないからです。

```
/gate            いまの状態を表示
/gate enforce    実行前に確認を出す
/gate shadow     知らせるだけに戻す (既定)
/gate off        止める
```

引っかかった判定は `~/.pi/agent/foreman-gate.log` に 1 行ずつ残ります。

## 何が外に出るか

判定のたびに `api.typesafe.ai` へ送ります。

| 層 | 送るもの | 送らないもの |
|---|---|---|
| foreman | 依頼文の全文、リポジトリ名、`AGENTS.md` の先頭数行、未コミットのファイル数 | ファイルの中身 |
| gate | ツール名、引数 (400 文字まで)、依頼文の先頭 1200 文字、手元で調べた事実 | ファイルの中身。長さと行数に置き換えます |

**`bash` のコマンド文字列は 400 文字までそのまま出ます。**
`curl -H "Authorization: Bearer ..."` のようなコマンドを判定させれば、そのトークンも一緒に出ます。

**依頼文もそのまま出ます。** 秘密や社外秘を含む依頼をする環境では、拡張を読み込まないか、
送る前に落とす仕組みを足してください。

API キーは環境変数からのみ読みます。

## 質問文を変えるとき

質問文は 1 語変えるだけで、狙った項目とは別の項目のスコアが動きます。触ったら必ず回してください。

```bash
npm run check                          # ルール表と安全弁 (ネットワーク不要)
TYPESAFE_API_KEY=... npm run fixtures  # 質問文を jev に実際に問う
```

`tests/fixtures.json` には、通ってほしい例と、引っかかってほしくない例の両方が入っています。
新しく誤りを見つけたら、直す前にまず例として足してください。
